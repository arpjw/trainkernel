# Security policy

TrainKernel is an experimental compiler and does not provide a production
security boundary. Do not use it with secrets or untrusted generated code.

Security fixes are provided for the current `0.1.x` research-preview line.

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting for `arpjw/trainkernel`. Include a minimal reproduction, affected
revision, and environment details that do not contain credentials. Never send
API keys, private keys, tokens, or private datasets in an issue.
